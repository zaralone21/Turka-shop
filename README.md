# Підготовка магазину

Робочий вебзастосунок для підготовки до відкриття невеликого магазину білизни, шкарпеток і домашніх тапок.

**Розділи:** головна (сьогодні, бюджет, постачальники, закупівлі, нотатки, AI-підказки), планер, нагадування, AI-менеджер, постачальники, товари та ціни, закупівлі, нотатки, бюджет відкриття, беззбитковість, дані й акаунт.

Адреса: `https://zaralone21.github.io/Turka-shop/`

## Як це влаштовано

| Частина | Де працює | Що потрібно |
|---|---|---|
| Сайт | GitHub Pages | нічого, публікується автоматично |
| Облікові записи, база, синхронізація | Supabase (Postgres + Auth + Realtime) | безкоштовний проєкт Supabase і 3 секрети в GitHub |
| Нагадування за розкладом і web push | Supabase: pg_cron щохвилини викликає функцію `send-reminders` | те саме; ключі VAPID створюються автоматично |
| AI-менеджер | функція `ai-chat` у Supabase викликає Claude | секрет `ANTHROPIC_API_KEY` |

Без секретів Supabase сайт працює як раніше: дані в браузері, без входу й синхронізації, AI показує «Потрібне підключення AI».

## Підключення сервера (один раз)

1. Створіть проєкт на [supabase.com](https://supabase.com) (безкоштовний план підходить). Запам'ятайте пароль бази.
2. Візьміть:
   - **Project ref**: частина адреси проєкту `https://<ref>.supabase.co` (Project Settings → General).
   - **Access token**: Account → Access Tokens → Generate new token.
3. У GitHub: Settings → Secrets and variables → Actions → New repository secret:
   - `SUPABASE_PROJECT_REF`
   - `SUPABASE_ACCESS_TOKEN`
   - `SUPABASE_DB_PASSWORD`
   - `ANTHROPIC_API_KEY` (необов'язково, для AI; ключ з [console.anthropic.com](https://console.anthropic.com))
4. Запустіть Actions → «Тести й публікація» → Run workflow (або зробіть будь-який пуш у `main`).

Автодеплой сам: застосує міграції бази, розгорне серверні функції, задасть секрети (ключ AI, секрет планувальника, ключі push), увімкне планувальник нагадувань, пропише адресу сайту для листів підтвердження й збере сайт з адресою сервера.

Ключ AI зберігається лише в секретах Supabase. У код сайту й у репозиторій він не потрапляє. У збірку сайту потрапляють лише адреса проєкту й публічний ключ, а доступ до даних обмежують правила бази (кожен бачить лише свої записи).

Необов'язкові налаштування функцій (Supabase → Edge Functions → Secrets): `AI_MODEL` (типово `claude-opus-5-5`), `AI_EFFORT` (`low`/`medium`/`high`, типово `medium`), `AI_DAILY_LIMIT` (запитів на користувача за добу, типово 300).

## Дані

- **Після входу** записи зберігаються в базі й синхронізуються між пристроями в реальному часі. На пристрої лишається копія для роботи без інтернету; зміни досилаються, щойно з'явиться зв'язок.
- **Перенесення зі старої версії.** Якщо в браузері є записи з попередньої версії, після входу застосунок запропонує завантажити резервну копію і перенести записи. Старі дані не видаляються, доки перенесення не перевірено на сервері, а очистити їх можна лише вручну.
- **Резервна копія**: Дані й акаунт → Експорт у JSON. Відновлення з файлу перевіряє файл і просить підтвердження.
- **Демо-режим** тримає вигадані приклади окремо від ваших записів.

## Нагадування й сповіщення

- Нагадування одноразові або повторювані, час за Києвом, з прив'язкою до завдання, постачальника чи закупівлі. Статуси: заплановано, відкладено, виконано.
- Сервер щохвилини перевіряє нагадування. Кожне спрацювання записується в журнал з унікальним ключем, тому одне нагадування не надсилається двічі навіть за паралельних запусків.
- Push-сповіщення вмикаються кнопкою «Увімкнути сповіщення» в розділі «Нагадування» на кожному пристрої окремо. Там же є тестове сповіщення.
- На iPhone і iPad push працює лише з іконки на головному екрані («Поділитися» → «На початковий екран»), iOS 16.4 або новіша.
- Без сервера нагадування видно в застосунку (дзвіночок і головна), але коли сторінку закрито, вони не приходять.

## AI-менеджер

Відповідає на питання про бюджет, постачальників, товари, ціни, закупівлі й справи; показує прострочене; порівнює пропозиції; перевіряє план закупівлі на вміщення в бюджет; знаходить застарілі й відсутні дані; створює завдання, нотатки й нагадування з повідомлення; готує чернетки повідомлень постачальникам.

- Модель бачить лише ті записи, які запитує інструментом для конкретного питання.
- Усі суми рахують функції застосунку (`src/core/calc.js`), модель лише пояснює.
- Створення завдань, нотаток і нагадувань виконується одразу з кнопкою «Скасувати». Зміни й видалення, масові й фінансові зміни виконуються лише після підтвердження з переліком «було → стане».
- Нічого не надсилає й не замовляє сам.

## Розробка

```bash
npm install
npm run dev            # сайт без сервера
npm test               # тести розрахунків, синхронізації, перенесення, AI-інструментів
scripts/test-sql.sh    # правила доступу й захист від дублів на локальному Postgres
npm run build          # збірка в dist/
```

Локально з сервером: `npx supabase start`, потім `VITE_SUPABASE_URL=http://127.0.0.1:54321 VITE_SUPABASE_ANON_KEY=<publishable key> npm run dev` і `npx supabase functions serve --env-file <файл з ANTHROPIC_API_KEY, VAPID_*, CRON_SECRET>`.

## Структура

```
src/core/            логіка без інтерфейсу
  schema.js          структура даних, версія, міграції, перевірка імпорту
  repo.js            єдина точка змін даних, синхронізація з сервером
  storage.js         сховище в браузері
  cloud.js           вхід, синхронізація в реальному часі, перенесення записів
  cloudAdapter.js    збереження в базу лише змінених записів, робота без інтернету
  calc.js, checks.js розрахунки й автоматичні перевірки
  reminders.js       час за Києвом, повтори, відкладення
  aiTools.js         інструменти AI над записами
  aiAgent.js         цикл розмови з моделлю
src/ui/              інтерфейс (views/ — по файлу на розділ)
public/              service worker, маніфест, іконки
supabase/migrations  таблиці, правила доступу, планувальник
supabase/functions   ai-chat, send-reminders, push
tests/               тести Vitest і SQL
```
