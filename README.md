# Підготовка магазину

Особистий дашборд для підготовки до відкриття невеликого магазину білизни, шкарпеток і домашніх тапок. Працює в браузері, без сервера й реєстрації.

**Розділи:** головна, постачальники (з товарами й цінами всередині картки), товари та ціни, нотатки, планер, бюджет відкриття, калькулятор беззбитковості, дані та резервна копія.

## Як користуватися

- **Онлайн:** після публікації на GitHub Pages застосунок відкривається за адресою `https://zaralone21.github.io/Turka-shop/`.
- **Без інтернету:** зберіть проєкт (`npm run build`) і відкрийте `dist/index.html` подвійним кліком. Це один самодостатній файл.

## Де зберігаються дані

У сховищі браузера (`localStorage`) на конкретному пристрої. Дані нікуди не надсилаються. Для перенесення між пристроями й резервної копії використовуйте **Дані → Експорт у JSON** і **Відновлення з файлу**. Перед імпортом файл перевіряється, а заміна потребує підтвердження.

Демо-режим тримає вигадані приклади в окремому сховищі й не чіпає ваших записів.

## Розробка

```bash
npm install
npm run dev     # локальний сервер із перезавантаженням
npm test        # тести розрахунків і перевірки імпорту
npm run build   # збірка в dist/index.html
```

Кожен пуш у `main` проганяє тести, збирає застосунок і публікує його на GitHub Pages (`.github/workflows/deploy.yml`).

## Структура

```
src/
  core/            логіка без інтерфейсу
    utils.js       форматування гривні, дат ДД.ММ.РРРР, чисел
    schema.js      структура даних, версія, міграції, перевірка імпорту
    storage.js     адаптери сховища (localStorage, пам'ять)
    repo.js        єдина точка змін даних: створення, редагування, видалення
    calc.js        бюджет, націнка й маржа, беззбитковість
    demo.js        демонстраційні дані
  ui/
    shared.js      стан інтерфейсу та спільні елементи
    shell.js       каркас: бокове меню, нижнє меню на телефоні, кнопка «+»
    views/         по файлу на кожен розділ
    modal.js       вікна, підтвердження, поля форм
    forms.js       форми записів
    backup.js      експорт та імпорт JSON
    events.js      обробка натискань
  main.js          запуск
tests/             тести Vitest
```

### Як розширювати

- **Нове поле запису:** додайте його в нормалізатор у `schema.js`, у форму в `forms.js` і у відповідний розділ у `views/`.
- **Зміна структури даних:** збільште `SCHEMA_VERSION` в `utils.js` і додайте міграцію в `MIGRATIONS` у `schema.js`. Старі збереження й файли експорту оновляться автоматично.
- **Сервер, база даних, синхронізація:** напишіть адаптер з тими самими методами `load()`, `save(data)` і `clear()`, що й у `storage.js`, і підключіть його в `repo.js`. Інтерфейс змінювати не потрібно.

## Обмеження першої версії

- Дані живуть в одному браузері. Очищення даних сайту їх видалить, тому регулярно робіть експорт.
- Немає синхронізації між пристроями й кількох користувачів.
- Немає складського й бухгалтерського обліку.
