# КОМФОРТ home — оновлення особистого дашборду

Затверджений мінімалістичний дизайн збережено.

## Додано

- Загальний пошук у товарах, контактах, нотатках, справах, закупівлях та інших записах. Кнопка в шапці або Ctrl+K.
- Швидкий запис: сума, «сьогодні», «завтра», «післязавтра» чи дата ДД.ММ.РРРР розпізнаються локально. Тип, назва, сума й дата завжди перевіряються перед збереженням. Витрата створюється як планова, не сплачена.
- Фінанси → Платежі: залишки разових витрат і найближча оплата щомісячних статей. Дата разової витрати задається в її формі. День щомісячної оплати — у формі щомісячної статті або приміщення для оренди. Оренда не дублюється. Щомісячні платежі показані за поточний місяць; давні борги не визначаються автоматично.
- Позначка оплати: для разової витрати оновлюється сплачена сума, для щомісячної — місяць оплати. Окремі дублікати витрат не створюються. Помилкову щомісячну позначку можна прибрати в календарі.
- Закупівлі → Перша закупівля: позначка в наявній формі, кількість, закупівельна й роздрібна ціна, доставка та підсумок. Ціни з каталогу підставляються під час вибору товару. Прогноз виручки приховано, якщо дані неповні. Закупівля вноситься в бюджет наявною кнопкою, один раз.
- Історія до 60 редагувань поточного сеансу з безпечним скасуванням. Якщо ті самі поля вже змінені, старе скасування блокується. Історія очищується після перезавантаження, імпорту, скидання або перемикання облікового запису/демо. Фото, файли, створення й видалення не входять до історії. Це не постійний журнал аудиту.
- Позначка «Магазин уже відкрито» в плані відкриття: приховує підготовку з головної; план і записи залишаються доступними. Режим можна повернути.

## Спрощено

Із головної прибрано лічильники товарів і постачальників, загальне меню додавання та несуттєві попередження про заповнення полів. Залишено справи, платежі, гроші, доставки, нотатки та проблеми, що потребують дії.

## Файли та дані

Оформлення: src/minimal.css. Нові функції: src/core/workspace.js, src/ui/workspace.js. Наявні форми, репозиторій і нормалізацію розширено сумісними необов’язковими полями. Нових колекцій чи SQL-міграцій не потрібно: поля зберігаються в JSON наявних записів і потрапляють до експорту.

Оновлений comfort-minimal-preview.html можна відкрити у браузері; демо доступне через «Дані й акаунт» → «Відкрити демо». Збережено попереднє ім’я HTML, щоб можна було оновити наявний перегляд. Локальна HTML-збірка без налаштувань Supabase використовує сховище браузера.

Для робочого сайту перенесіть джерельні файли до наявного репозиторію, збережіть власні .env та секрети GitHub/Supabase й використайте наявний workflow. Живий сайт не змінено. Архів не містить ключів, реальних записів, node_modules чи production-збірки з параметрами вашого сервера.

## Перевірено

90 тестів у 8 файлах і збірка Vite. У демо перевірено створення витрати зі швидкого запису, пошук і відкриття знайденого запису, редагування та скасування суми, позначку разової й щомісячної оплати, повернення щомісячної позначки, збереження першої закупівлі з цінами каталогу й доставкою, режим після відкриття, мобільну форму та історію. Створені під час перевірок тестові витрата й закупівля видалені з демо.

Робочий AI, production-база та доставка push локально не перевірялися: налаштування сервера відсутні.

Розробка: npm ci, npm run dev. Перевірки: npm test, npm run build.
